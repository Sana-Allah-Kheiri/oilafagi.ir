# Afagi Super Service — oilafagi.ir 🛠️

Minimal home page for Afagi Super Service, Urmia (est. 1360) — Auto periodic service, automatic gearbox oil change with machine, engine oil + largest oil shop in West Azerbaijan.

**Stack:** React 18 + Vite 5 + TypeScript + Tailwind CSS 3 + RTL (fa)

## Features
- Sticky smart header (hide on scroll down / show on scroll up)
- Hero with Free Consult `09144413979` + Booking `04433821430`
- Floating buttons: Call, WhatsApp, Instagram, Telegram, Rubika
- Dark / Light theme from `dark_oilafagi_theme.json` / `light_oilafagi_theme.json`
- PWA install prompt (`vite-plugin-pwa`)
- Pattern: frontdesign.ir/macchina

## Run
```bash  
npm i  
npm run dev  
npm run build # -> dist/ upload contents to public_html on DirectAdmin
